## 🚨 Reporting a Vulnerability

The Sigil project takes supply-chain security and cryptographic correctness with extreme seriousness.

If you discover a potential vulnerability, cryptographic flaw, or security issue, please **DO NOT** create a public GitHub issue.

Instead, please send an encrypted report to:
`security@sigil-project.org` (or directly via private security advisory on GitHub).

### What to Include in Your Report:
1. Clear description of the vulnerability.
2. Step-by-step reproduction instructions or proof-of-concept (PoC).
3. Impact assessment (e.g. signature bypass, path traversal, replay attack).
4. Any proposed remediations.

We will acknowledge receipt within 24 hours and provide an estimated timeline for coordination and public disclosure.
